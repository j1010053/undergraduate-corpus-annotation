標註自動存於此瀏覽器，不跨裝置同步。工作結束或換裝置前，請先匯出備份。

從一筆語料開始

  1. 從左側選擇語料，或搜尋全文、Text ID、語料位置與標註。
  2. 切換短、中、長語境；查詢詞以底色標示。需要核對時切換「原始斷詞」或「詞性標註」。
  3. 在右側選狀態、加標籤、記備註。可用「自訂欄位」新增文字欄或分類選單。
  4. 按「完成並下一筆」繼續檢閱。工作結束時匯出 JSON 備份，或含標註的離線網頁。

資料與保存

此頁抽出原始 concordance 編號 1–10，共十筆語料；每筆保留三種長度的語境、Text ID 與語料起訖位置。長語境是匯出檔所含的範圍，不代表完整原文。年份取自 Text ID。

標註自動暫存在目前瀏覽器，不會寫回原始檔案，也不會跨裝置同步。請定期匯出備份。原始語料庫連結可能需要登入或因查詢過期失效。
