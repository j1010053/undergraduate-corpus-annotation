開始 pre-coding

  1. 左側選擇語料組別，或搜尋全文、Text ID、原始編號及標註。
  2. 查詢詞以底色標示；前後 10／40 詞方便定位，「完整語境」提供匯出檔中的全部前後文。需要核對時切換原始斷詞或詞性。
  3. 右側選檢閱狀態、加分類標籤、記下判斷依據。用「自訂欄位」新增或修改分類選單與文字欄。
  4. 按「完成並下一筆」繼續目前篩選的清單。工作結束後，匯出 JSON 備份；另可匯出 CSV 或含標註的離線網頁。

抽樣與來源

四組各取最多 15 筆，不足則全取。S01 起是本次樣本編號；「原始 #」是該來源檔中的命中編號。固定 seed 與逐筆抽樣清單可在「抽樣紀錄」查看，重新整理不會重新抽樣。完整語境仍是匯出片段，不一定是完整句子或全文；口語未自行補標點或切分說話者，年份取自 Text ID。

保存與換裝置

標註自動存於目前瀏覽器，不跨裝置同步。匯出 JSON 後可備份到 GitHub，換裝置再匯入。CSV 供分析；還原請用 JSON。此樣本使用獨立暫存，原前十筆網頁的備份無法直接套用。原始語料庫連結可能需要登入或因查詢過期失效。

保存你的檢閱成果

CSV 供分析使用；還原標註請使用 JSON。下載後請確認檔案已保存。

將備份存到 GitHub

  1. 先下載上方的「JSON 備份」，需要試算表時也可下載 CSV。
  2. 開啟 GitHub 上傳頁面 ↗，選擇剛下載的檔案，再按「Commit changes」保存。
  3. 換裝置時，從 GitHub 下載 JSON，再用本頁的「匯入備份」繼續標註。

上傳需要登入 GitHub，並有此儲存庫的寫入權限。公開庫中的備份任何人都能讀取。此頁不會自動上傳或同步標註。
